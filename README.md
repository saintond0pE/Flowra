## 🎨 Design Philosophy: Neo-Brutalist Kineticism

This isn't your average "clean" corporate template. FLOWRA uses a **Neo-Brutalist design language** (aka the "Kinetic Manifesto") characterized by:
- **High Contrast**: Bold black #000000 borders and vibrant secondary accents (`#FFC837`, `#10B981`).
- **Tactile UI**: 6px and 8px block shadows that make components feel physically present on the screen.
- **Micro-Animations**: Kinetic pulse effects across pipelines and interactive form elements.
- **Inter Typography**: Heavy-weight, ultra-modern font-face for maximum impact.

## 🛠️ Tech Stack & local Dev

This project is built for **performance first**. No heavy frameworks, no bloated dependencies.
- **Core**: Vanilla HTML5 / Javascript.
- **Styling**: Vanilla CSS3 + Neo-Brutalist utility classes.
- **Icons**: Material Symbols (Weight 700 / High Contrast).
- **Hosting-Agnostic**: Static file architecture, ready to push to any CDN.

### Run Locally
To spin up the FLOWRA system kingdom on your machine:
```bash
# Clone the repo
git clone https://github.com/saintond0pE/Flowra.git
cd Flowra

# Start a local server (Requires Python)
python -m http.server 8000
```
Then visit: `http://localhost:8000`
