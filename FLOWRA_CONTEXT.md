# Flowra AI Project Context
**Goal**: Build industrial-grade AI automation systems (Flowra OS) for businesses.

## Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Styling**: Tailwind CSS (via CDN), Google Fonts (Inter).
- **Backend**: Supabase (Auth, Firestore-like Database).
- **Deployment**: Vercel.

## Design DNA: Neo-Brutalism
- **Palette**: 
  - #FFF9E6 (Base/Background)
  - #FFC837 (Secondary - Yellow)
  - #10B981 (Tertiary - Green)
  - #38BDF8 (Accent - Light Blue)
  - #B19CD9 (Action - Purple)
  - #FF8A65 (Secondary Accent - Orange)
- **UI Elements**: Sharp 0px borders, 4px black solid outlines, heavy black block shadows (neo-shadow), bold/black typography (Inter).
- **Vibe**: High-energy, "No-Nonsense", "Kinetic", Industrial textures, Triple-layer marquees.

## Core Structure
- `index.html`: Main marketing landing page.
- `dashboard.html`: Internal Flowra OS command center (Supabase integrated).
- `login.html`: Secure auth portal for administrators.
- `pages/`: Specialized marketing and information pages (Pricing, Case Studies, etc.).
- `assets/`: Project images and media.

## Cursor/Copilot Instructions
- Maintain the Neo-Brutalist aesthetic: sharp borders, bold shadows, and high contrast.
- When adding logic, prioritize Vanilla JS and Supabase integration.
- Ensure all new pages or components follow the existing design tokens in `styles.css`.
